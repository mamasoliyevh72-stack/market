# market

MARKETS - Onlayn do'kon va boshqaruv paneli (Admin Panel).

## Texnologiyalar
- **Backend:** Node.js, Express
- **Ma'lumotlar bazasi:** PostgreSQL
- **Frontend:** HTML5, Tailwind CSS, Vanilla JavaScript, Lucide Icons

## O'rnatish va Ishga tushirish
1. Bog'liqliklarni o'rnatish:
   ```bash
   npm install
   ```
2. Loyihani ishga tushirish:
   ```bash
   npm start
   # yoki dev rejimida
   npm run dev
   ```
3. Brauzerda ochish:
   - Do'kon: `http://localhost:5000`
   - Boshqaruv paneli: `http://localhost:5000/admin`
